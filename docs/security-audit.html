Boas Práticas de Segurança e Auditoria de Acesso

Proteja sua instância DHIS2 e seus dados sensíveis com nossas ferramentas de auditoria de segurança proativas.

O Perigo do Acesso Público

Uma das vulnerabilidades mais comuns no DHIS2 é o compartilhamento acidental de metadados ou visualizações com "Public Access". O Audit Vision detecta automaticamente essas configurações.

Auditoria de Compartilhamento (Sharing)

Nossa página de Security Audit lista todos os objetos que possuem acesso público habilitado. Você deve revisar esta lista periodicamente para garantir que:

  • Data Sets: Nunca tenham acesso público habilitado para entrada de dados.
  • Organisation Units: Sejam visíveis apenas para os grupos de usuários autorizados.
  • Programs: Contendo dados de pacientes (Tracker) devem ter restrições de segurança rigorosas.

Checklist de Saúde do Sistema

O Audit Vision realiza verificações automáticas periódicas:

1

Credenciais Padrão

Verificamos se existem usuários com senhas óbvias (admin/district).

2

SSL/TLS

Auditamos se sua conexão está criptografada com certificados válidos.

3

MFA (Multifator)

Monitoramos a adoção da autenticação de dois fatores entre seus usuários admin.

4

Versão do Sistema

Alertamos quando você estiver rodando uma versão do DHIS2 com vulnerabilidades conhecidas.

Score de Segurança

Nossa métrica agregada ajuda você a entender rapidamente o quão protegida está sua instância. Tente manter seu score acima de 85%.
