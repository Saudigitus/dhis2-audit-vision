Change Explorer: O Rastreador de Mudanças

Entenda como o DHIS2 Audit Vision rastreia cada modificação nos seus metadados, oferecendo uma visão clara de "antes e depois" para cada objeto.

O Change Explorer

O Change Explorer é o coração da nossa ferramenta. Ele permite que você navegue por uma lista cronológica de todas as ações (CREATE, UPDATE, DELETE) realizadas no sistema.

Visualização em Diff

Quando você clica no ícone de visualização em uma mudança de UPDATE, o Audit Vision abre um painel lateral mostrando exatamente quais campos foram alterados:

  • Campo Alterado: O nome do atributo (ex: `name`, `shortName`, `categoryCombo`).
  • Antes: O valor anterior ao salvamento.
  • Depois: O novo valor que está agora no sistema.

Auditoria de Usuários

Além dos metadados, auditamos quem está fazendo o quê. Na página de User Audit, você pode filtrar por um usuário específico para ver todo o seu histórico de ações.

Isso é vital para depurar alterações acidentais ou investigar possíveis acessos não autorizados.

Sistema de Filtros Inteligentes

Você pode refinar sua busca usando nossos filtros globais:

Por Tipo

Ex: Filtrar apenas por Data Elements ou Programas.

Por Período

Ex: Ver mudanças ocorridas apenas nas últimas 24 horas.

Por Risco

Ex: Filtrar apenas por ações de DELETE (Alta Prioridade).

Exportação de Relatórios

Precisa apresentar os resultados para uma auditoria externa? Você pode exportar qualquer visualização em formato PDF ou CSV com apenas um clique.
