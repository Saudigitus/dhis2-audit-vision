# User Guide

Welcome to the **DHIS2 Audit Vision** User Guide. This section provides a detailed overview of how to use the platform to monitor and audit changes in your DHIS2 system.

DHIS2 Audit Vision is organized into several main sections that allow you to analyze different aspects of audit data:

- **Dashboard**: A quick overview of today's activities and historical trends.
- **Change Explorer**: A detailed tool for exploring specific changes in metadata and data.
- **Metadata Grouping**: [Logical grouping of changes](./metadata-grouping) for easier analysis.
- **User Audit**: [Analysis focused on the actions](./user-audit) of specific users.
- **Severity Rules**: [Configuration of rules](./severity-rules) to identify critical or risky changes.
- **Settings**: General application settings.

In this guide, we will explore each of these features so you can get the most out of the tool.
